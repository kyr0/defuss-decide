Typed decisions over your data, right in the browseron WebGPUin Node.js and Bunoffline, on the device

Run typed decisions on text and images right in your browser, or in Node.js and Bun: yes/no and multiple choice, entities, personal data, evidence, relations, image regions and OCR checks. The model, kyr0/winzling-decide-1.0, builds on Vela3-fast by the vLLM Semantic Router team and is optimized to be much smaller while keeping its answers, so it runs fast on edge devices.

Why it is different

§Small models that stay close to the originals

One library, every runtime

Node.js, Bun and the browser run the same code on the same models: WebGPU where the device has it, else WASM or the CPU.

Downloads you can ship

The q4 bundles share one backbone file: all four text tasks take 482 MB instead of 6.1 GB as full-precision bundles.

Your question, no training

Write any yes/no or multiple-choice question in plain words. The answer comes with a probability per option and references to the fields it read.

Same answers as the original

Every bundle reproduces the original model's outputs on its reference inputs. A bundle that fails the check does not load.

Exact offsets

Spans, entities and personal data come with character offsets into your input, correct for any Unicode text.

Private by design

Only the model files download. State, questions and images stay in the tab or the process.

    Graph relations. Rank paragraphs by how they relate to a statement, as edges of a knowledge graph: supports (the paragraph states that it is true), refutes (states that it is false) and relates (same topic). The decision head answers one four-option question per paragraph, without training for the task; it ranks by what a paragraph states, including stated causes and qualifiers.

          Where a run loads its bundles

          A run downloads the real bundles of kyr0/winzling-decide-1.0 from Hugging Face as Brotli files, keeps them in the browser's cache and answers with the library code shown under "Get started". Each task loads its smallest bundle unless you pick a larger precision; the text decision bundle in q4 changes 3 of 177 test answers against FP32. For your own exported bundles, run make demo and enter /models/, or any folder laid out like the repository with .br copies.

          How it works

          §From your input to a typed answer

          A question runs up to four small models one after another, all inside ONNX Runtime. The models return numbers, never generated text, so every answer can be checked against the input.

          §No model writes text

          The models return probabilities, spans of your input and boxes. Every reference points into what you sent.

          §Everything runs where you call it

          ONNX Runtime runs the bundles on WebGPU, WASM or the CPU. Only the model files are downloaded, once, and the browser caches them.

          §Checked on every export

          A bundle is written only after ONNX Runtime matched the original PyTorch model on recorded inputs, and it loads only with that mark.

          Measured, not promised

          §Size, speed and fidelity in numbers

          Every value comes from the project's recorded measurements: how much a browser downloads, how long a question takes, and how close the smaller bundles stay to full precision.

          Get started

          §Add it to your own app in four steps

          1. 1

            §Install the package

            Pick your package manager. The library runs in Node.js 22 or later, Bun and current browsers.

            bun add defuss-decide
            pnpm add defuss-decide
            npm install defuss-decide
            yarn add defuss-decide
          2. 2

            §Download the model

            For Node.js and Bun, download kyr0/winzling-decide-1.0 into models/, where the library looks by default. Browsers load it from Hugging Face by themselves.

            hf download kyr0/winzling-decide-1.0 --exclude "*.br" --local-dir models
          3. 3

            §Ask in Node.js or Bun

            Load the bundles once, then ask typed questions about your state.

            import { loadVelaProvider } from "defuss-decide/node";
             
            // Every task of kyr0/winzling-decide-1.0 from models/, each in its smallest published precision.
            const vela = await loadVelaProvider();
            try {
              const r = await vela.systemOne({
                state: { order: { id: 17, status: "delivered", items: [{ sku: "A1", ordered: 2, shipped: 2 }] } },
                questions: { fulfilled: { type: "decide", instructions: "Is the order fulfilled?" } },
              });
              const { decision, probabilities, evidence } = r.answers.fulfilled;
              console.log(decision, probabilities.yes.toFixed(2));
              // => yes 0.97
              console.log(JSON.stringify(evidence.map((s) => s.state_ref)));
              // => [["order.status"]]
            } finally {
              await vela.dispose();
            }
          4. 4

            §Or in the browser

            The same API runs in the tab, on WebGPU when the device has it.

            import { loadVelaProvider } from "defuss-decide/web";
             
            const vela = await loadVelaProvider(
              {
                fast: { ner: "/models/vela3-fast-onnx/ner/q8/" },
                vision: { box: "/models/vela3-fast-onnx/vision-box/q8/" },
              },
              { backend: "auto" },
            );
            try {
              const text = await vela.systemOne({
                state: "Ada Lovelace lived in London.",
                questions: { entities: { type: "span", criteria: ["person", "city"] } },
              });
              console.log(JSON.stringify(text.answers.entities.spans.map((s) => s.text)));
              // => ["Ada Lovelace","London"]
             
              // images: File or Blob objects from an <input type="file">, image URLs, or {data, width, height} RGB bytes
              const where = await vela.systemOne({
                images: ["/models/vela3-fast-onnx/vision-box/q8/sample.png"],
                questions: { square: { type: "box", instructions: "the red square" } },
              });
              console.log(where.answers.square.box.left.toFixed(2));
              // => 0.19
            } finally {
              await vela.dispose();
            }
